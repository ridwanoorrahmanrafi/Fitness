--------------------------------------------------------------------------------
Status: VERIFIED & TESTED
Database Endpoint: aws-0-us-east-1.pooler.supabase.com:6543 / postgres

Implementation Details:
1. Connection Architecture:
   - Directly connects via PostgreSQL transaction/session pooler on port 6543 using
     `pg.Pool` with SSL mode `rejectUnauthorized: false`.
2. Tables Created & Schema Validated:
   - `public.user`:
     Columns: id (text), name (text), email (text), emailVerified (bool),
              image (text), createdAt (timestamp), updatedAt (timestamp),
              hunterRank (text), hunterTitle (text)
   - `public.session`:
     Columns: id (text), expiresAt (timestamp), token (text), createdAt,
              updatedAt, ipAddress (text), userAgent (text), userId (fk)
   - `public.account`:
     Columns: id (text), accountId (text), providerId (text), userId (fk),
              accessToken, refreshToken, idToken, password (text), createdAt, updatedAt
   - `public.verification`:
     Columns: id (text), identifier (text), value (text), expiresAt (timestamp),
              createdAt, updatedAt
   - `public.hunter_stats`:
     Stores player leveling stats, allocated points, and daily streak.
   - `public.hunter_workouts`:
     Stores completed dungeon raid combat logs.
3. Security & Row Level Security:
   - Better Auth handles hashed credentials using PBKDF2/scrypt.
   - Environment variables isolate database passwords from source control.
